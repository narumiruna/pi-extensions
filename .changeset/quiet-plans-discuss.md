Add free discussion within Plan mode. Switch with F2 when no native Pi binding uses it, or use the active `/plan` menu. Switching discards unfinished questionnaire answers without changing the main prompt draft. Discussion keeps read-only restrictions and stores completed plans without opening an automatic action menu. Restore the interaction mode with the workflow; new workflows start with questionnaires enabled.
