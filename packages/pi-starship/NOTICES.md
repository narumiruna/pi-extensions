# Notices

pi-starship's format and style behavior are based in part on Starship. Its bundled presets adapt
colors and layouts from [Starship](https://starship.rs/presets/), Lualine, Tmux themes,
Powerlevel10k, and Oh My Posh to Pi's native runtime snapshots. They do not run the upstream
configuration logic. pi-starship uses the `yaml` package to parse kubeconfig and OpenStack metadata
as inert local data.
